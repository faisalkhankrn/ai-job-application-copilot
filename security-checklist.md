# Public Repository Security Checklist

Complete this checklist before each GitHub upload.

## Workflow JSON

- [ ] No API key is visible.
- [ ] No OAuth access or refresh token is visible.
- [ ] No password is visible.
- [ ] No private webhook URL is visible.
- [ ] No production spreadsheet ID is visible.
- [ ] No personal email address is visible.
- [ ] No private CV text is visible.
- [ ] No real recruiter or candidate data is visible.
- [ ] Credential names and identifiers have been reviewed.
- [ ] Test executions and pinned data have been removed where necessary.

## Screenshots

- [ ] Names are blurred.
- [ ] Email addresses are blurred.
- [ ] Tokens and URLs containing secrets are blurred.
- [ ] Spreadsheet IDs are hidden.
- [ ] Browser tabs do not reveal private information.
- [ ] Real application records are replaced with sample data.

## Files

- [ ] `.env` is not included.
- [ ] Google credential JSON files are not included.
- [ ] Private CV and cover-letter files are not included.
- [ ] Real tracker exports are not included.
- [ ] Only synthetic sample data is included.
